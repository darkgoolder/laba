## Цель
Измерить влияние фильтра Гаусса с σ = 3 на синтетическую сцену варианта 21 относительно чистого эталона.

## Данные и происхождение
- Данные синтетические, создаются функциями `make_gray4`, `scene4` и `clean4`.
- Внешние изображения не использовались.
- Размер: 128 × 128 пикселей.
- Сцена 4: шум 0,05; шахматная добавка с размером клетки 8; яркий круг на градиентном фоне.
- Эталон: `clean4(4)`, то есть чистая сцена без шума.

## Параметры запуска
- Номер варианта: `N = 21`.
- Номер сцены: `c = 4`.
- Номер операции: `k = 3`.
- Операция: фильтр Гаусса, `σ = 3`.
- Серия: `seeds = 101:105` (5 запусков).
- Представительное изображение: seed `101`.
- Практический допуск, зафиксированный до анализа: полезна при ΔPSNR ≥ +1 дБ; вредна при ΔPSNR ≤ −1 дБ; нейтральна при −1 < ΔPSNR < +1 дБ.
- Учебный критерий: `|Δ| > 2·s_base`.
